# 10秒リプレイ v0.3.2

[アプリを開く](https://yaokode.github.io/10sec-replay/)

- 選んだ秒数あとに自動表示、または直前の動きをスロー再生。
- 5・10・15秒、1・0.5・0.25倍。無料・広告なし、登録・インストール不要。
- 映像は端末のメモリ内だけで処理。音声収録・保存・共有・外部送信なし。配信サービスのアクセスログは別。
- 保持バッファは選択秒数＋0.8秒、最大15.8秒・画像計算値64MiB以内。入力映像・処理中画像・Canvas等は別。標準480×270・10fps目標、15秒は8fps。低め320×180・8fps。コマ間の補間なし。
- 見返し・一時停止時はカメラ停止、映像は最長60秒。連続撮影は15分で終了。「おわる」・タブ移動・ページ離脱でカメラと一時映像を解放。ブラウザー停止中の厳密な時限処理は保証しない。
- 学校端末の動作、実際の遅延、長時間の安定性、学校での利用可否は未確認。

HTML/CSS/JavaScriptのみ。外部ライブラリ、外部API、ビルド工程なし。

ローカルはこのディレクトリで `python3 -m http.server 8765 --bind 127.0.0.1`。公開時はHTTPSが必要です。

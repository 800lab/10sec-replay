# 10秒リプレイ v0.3.5

[アプリを開く](https://azurewood-lab.github.io/10sec-replay/)

- 選んだ秒数あとに自動表示、または直前の動きをスロー再生。
- 5・10・15秒、1・0.5・0.25倍。無料・広告なし、登録・インストール不要。
- 映像は端末のメモリ内だけで処理。音声収録・保存・共有・外部送信なし。配信サービスのアクセスログは別。
- 保持バッファは選択秒数＋0.8秒、最大15.8秒・画像計算値64MiB以内。入力映像・処理中画像・Canvas等は別。標準480×270・10fps目標、15秒は8fps。低め320×180・8fps。コマ間の補間なし。
- 見返し・一時停止時はカメラ停止。スロー再生中は最後まで保持し、再生終了・停止後、見返し操作がないまま60秒で消去。「もう一度」・再開中は途中消去せず、停止位置・速度・左右反転を操作すると無操作期限を数え直す。自動表示の一時停止画像は停止から60秒で消去。連続撮影は120分で終了。「おわる」・タブ移動・ページ離脱でカメラと一時映像を解放。ブラウザー停止中の厳密な時限処理は保証しない。
- 学校端末の動作、実際の遅延、長時間の安定性、学校での利用可否は未確認。

v0.3.5では、再生開始から一律60秒の消去を、停止後の無操作60秒へ変更。15秒・0.25倍や繰り返し再生の途中終了を防ぐ。取り込み・メモリ上限・120分のカメラ連続利用上限は変更していない。PC仮想カメラの過去120分結果はv0.3.3/0.3.4の取り込み処理の結果として再利用し、今回の版で120分を再実行したとは扱わない。学校端末の実カメラ・発熱・電源管理は別途確認する。

HTML/CSS/JavaScriptのみ。外部ライブラリ、外部API、ビルド工程なし。

ローカルはこのディレクトリで `python3 -m http.server 8765 --bind 127.0.0.1`。公開時はHTTPSが必要です。
